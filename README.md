# Smart To-Do Manager

A modern Java Swing-based task management application with a sleek UI and productivity tracking.

---

## ✨ Features
- Add, delete, and manage tasks
- Priority levels (High 🔥, Medium ⚡, Low 🍃)
- Deadline tracking
- Task completion toggle
- Progress tracking bar
- Stylish UI with gradient and glass effects

---

## 🛠 Tech Stack
- Java (Swing & AWT)
- File Handling (for persistence)

---

## 🚀 How to Run

1. Clone the repository:
   git clone https://github.com/RanpisePrafull/Smart-To-Do-Manager.git

2. Open in VS Code / IntelliJ

3. Compile:
   javac src/TodoApp.java

4. Run:
   java -cp src TodoApp
